禁止（会把两条线揉在一起或覆盖本地文件）
--------------------------------------
- 不要在 D:\ai 执行：git init、git checkout、git switch、git restore、git pull、git reset
- 不要 git add .
- 不要把 C 盘那个文件夹拖进 Cursor 当工作区打开后乱跑脚本
- 不要运行 bootstrap.ps1、commit-prototype.ps1（一次性初始化，日常禁用）


日常备份（只推对应那条线）
------------------------
改加藤惠 / 精灵图 / pack-kawaii 之后：
  powershell -File C:\Users\lirui\.grok-usage-pet-git\push-kawaii.ps1

改原型毛绒图 / pack.ps1 之后：
  powershell -File C:\Users\lirui\.grok-usage-pet-git\push-prototype.ps1

脚本只会 git add 各自清单里的文件，不会改 D:\ai 的内容。
不要提交：usage.json、usage.txt、pet_state.json、日志、dist、build。
