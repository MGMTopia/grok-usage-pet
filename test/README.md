# 加藤惠 Codex 桌面宠物资料包

这是当前已安装并修复左右拖动漂移的 Codex v2 桌面宠物资料包。

## 目录

- `pet/`：可安装资源，包含 `pet.json` 和 `spritesheet.webp`。
- `references/`：制作时使用的五张造型参考图。
- `previews/`：完整接触表、16 方向检查图以及各状态 GIF 预览。
- `qa/`：v2 图集校验、透明像素检查、方向语义检查和拖动注册数据。
- `backup/`：修复左右拖动漂移之前的精灵图，可用于回退。
- `tools/`：本次确定性注册和抽帧检查脚本。

## 当前资源规格

- 宠物 ID：`megumi-kato`
- 人物说明：`《路人女主的养成方法》的女主角。存在感淡薄却观察敏锐，性格温和随性，常以平静吐槽陪伴并默默支持同伴。`
- 精灵版本：`spriteVersionNumber: 2`
- 图集尺寸：`1536 × 2288`
- 单元格尺寸：`192 × 208`
- 布局：8 列 × 11 行
- 标准动画：9 组
- 注视方向：16 个

左右拖动修复后，核心身体的横向波动为：

- 向右：`7.608 px → 0.874 px`
- 向左：`12.021 px → 0.774 px`

最终安装文件已通过 v2 校验，无空帧、裁切、透明 RGB 残留或结构错误。

## 安装

1. 退出 Codex，或者稍后重新启动 Codex 以刷新资源缓存。
2. 将整个 `pet` 文件夹复制到：

   `%USERPROFILE%\.codex\pets\megumi-kato`

3. 确保目标目录内最终文件名为：

   - `pet.json`
   - `spritesheet.webp`

4. 启动 Codex，并在宠物选择界面选择“加藤惠”。

## 已知客户端行为

- 鼠标悬停主要触发跳跃动画。
- 普通鼠标移动并不一定触发 16 方向注视；当前客户端只有在特定界面提供位置点时才可能使用方向帧。
- 左右拖动会使用 `running-right` 和 `running-left` 两行动画。
